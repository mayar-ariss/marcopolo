# marcopolo

A skill for exploring unconventional designs for coding and architecture
problems. It reduces a problem to its hard constraints, names the
conventional solutions and the assumptions they rest on, generates
alternatives that each break a different assumption, then builds and
verifies the most promising one against the baseline. If no alternative
wins, it says so and delivers the conventional solution.

## Usage

Invoke it by name:

    marcopolo: design a rate limiter for a multi-tenant API

It also applies when you explicitly ask for a non-standard, novel, or
first-principles alternative to the usual approach.
